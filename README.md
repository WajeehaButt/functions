# Project Tasks

## Task 1 – Greeting Function

A reusable function displays a personalized welcome message by accepting a user's name as a parameter.

---

## Task 2 – Calculator

Separate functions are created for:

* Addition
* Subtraction
* Multiplication
* Division

Each function receives two numbers and returns the calculated result.

---

## Task 3 – Even and Odd Checker

A function determines whether a given number is even or odd and returns the appropriate message.

---

## Task 4 – Grade Calculator

The program calculates grades according to the obtained marks.

|    Marks | Grade |
| -------: | :---: |
|   90–100 |   A   |
|    80–89 |   B   |
|    70–79 |   C   |
|    60–69 |   D   |
| Below 60 |   F   |

---

## Task 5 – Largest Number

A function compares three numbers and returns the greatest value.

---

## Task 6 – Factorial Calculator

A separate function calculates the factorial of any positive integer using a loop.

---

## Task 7 – Temperature Converter

Two reusable functions are implemented:

* Celsius to Fahrenheit
* Fahrenheit to Celsius

---

## Task 8 – Student Result System

The project includes a simple student result management system that performs:

* Total Marks Calculation
* Percentage Calculation
* Grade Assignment
* Pass/Fail Decision
* Final Result Display

---

## Bonus Challenge – Banking System

A simple banking system is developed using functions that perform:

* Deposit Money
* Withdraw Money
* Check Available Balance
* Display Mini Statement

The system also validates incorrect transactions and prevents withdrawals that exceed the available balance.
